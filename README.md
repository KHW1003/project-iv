# [서비스명]

국내 곤충 사육자가 **종별로 필요한 정보만 바로 찾을 수 있는** 웹 커뮤니티.

종을 고르고 주제(산란, 유충 사육 등)를 누르면, 검증된 정리본과 그 주제의 게시판이 바로 열린다.
MVP는 국내 곤충으로 시작하고, 이후 등각류·절지류·파충류·양서류·어류로 넓힌다.

## 핵심 구조

```
분류군 → 과 → 종 → 종목(일반 / 극태 / 체장) → 주제(산란, 유충 사육 …)
```

- **종 페이지**: 기본정보부터 채집·산란·유충 사육까지 도감처럼 한 페이지에
- **주제 게시판**: 주제마다 정리본 + 방식 카드 + 게시판
- **정보 신뢰성**: 전문가 팁, "누구의 방식" 카드, 따라해봤어요 결과 집계
- **사육일지·캘린더** (3차): 개체별 기록, 방식에 맞춘 일정 자동 생성
